วิธีติดตั้งชุด Ready
1. หยุดหน้าต่างรันเว็บเดิมด้วย Ctrl+C ถ้าขึ้น Terminate batch job ให้ตอบ Y
2. แตก 45Fitness_Ready_v24.zip ลงโฟลเดอร์ใหม่ ห้ามรันจากใน ZIP
3. เปิด 45Fitness-Ready แล้วดับเบิลคลิก START-HERE.cmd
   หรือเปิด PowerShell ในโฟลเดอร์นี้แล้วรัน:
   powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\Run-Ready.ps1
4. ตัวเปิดจะหาโปรเจกต์เดิมใน D:\Robot Project\FitnessFormCoach_Python\FitnessFormCoach_Python
   หากไม่พบ ให้เลือก 1 แล้วเลือกโฟลเดอร์เดิมที่มี app.py และ data เพื่อใช้บัญชี/ประวัติเดิม
   ตัวเลือก 2 เป็นเว็บใหม่ฐานข้อมูลว่าง ไม่ใช้ข้อมูลจากโฟลเดอร์เดิม
5. เปิด http://127.0.0.1:5000/45-fitness-coach แล้ว Ctrl+F5
   มือถือปิดแท็บเดิมแล้วเปิดใหม่ หากต้องสร้างลิงก์แชร์ ใช้ OPEN-MOBILE-LINK.cmd ในโฟลเดอร์ที่ติดตั้ง
6. ข้อมูลสมาชิก ประวัติ และ SMTP อยู่ใน data เดิม ไม่มีการคัดลอกทับ data

การตรวจท่า
- ปรับการคำนวณทั้ง 15 ท่าดัมเบลให้ใช้มุมข้อต่อและความเอียงลำตัวจากพิกัด 3 มิติที่โมเดลประมาณได้เป็นหลัก
- แก้กรณีหันหน้าเข้ากล้องแล้วแนวก้มตัวของ Row ถูกอ่านว่าตัวตรง
- มุมหน้าหรือด้านข้างใช้ได้เมื่อข้อต่อที่ต้องใช้มีความชัดเจน หากแขน/ขาบังกันหรือพิกัดประเมินไม่ชัด ให้ขยับกล้องเฉียงเล็กน้อย
- วิดพื้นรองรับมุมหน้าและข้างด้วยพิกัด 3 มิติ ตรวจแนวสะโพก/เข่าและการงอ–เหยียดศอกก่อนนับ ลงแล้วกลับขึ้นจึงเป็น 1 ครั้ง
- หากโมเดลไม่มีพิกัด 3 มิติ วิดพื้นใช้การวัด 2 มิติเดิมซึ่งต้องเห็นแนวตัวด้านข้างชัด ไม่สร้างข้อมูลความลึกขึ้นเอง
- โดดตบใช้ระยะและมุม 3 มิติเมื่ออ่านได้ ช่วยลดผลของการหมุนตัวด้านข้าง แต่ต้องเห็นข้อต่อทั้งสองข้างครบ
- การหายไปจากภาพ เปลี่ยนแหล่งพิกัด หรือเปลี่ยนข้างที่ตรวจวิดพื้น จะตัดรอบค้าง ป้องกันนับต่อจากคนละช่วง
- ระบบเป็นการประมาณจากกล้องเดียว ไม่รับรองการตรวจฟอร์มทุกส่วนหรือทุกมุมที่ถูกบัง

ท่าเตรียมหมวดไหล่
- Lateral Raise: ถือดัมเบลข้างขา ค้างนิ่ง 2 วินาที แล้วยกออกข้าง
- Front Raise: ถือดัมเบลหน้าขา ค้างนิ่ง 2 วินาที แล้วยกไปหน้า
- Shoulder Press: เริ่มถือดัมเบลข้างขาได้ ค้างนิ่ง 2 วินาที แล้วนำดัมเบลมาระดับไหล่ก่อนดันเหนือศีรษะ
  การยกจากขาเข้าระดับไหล่เป็นการเตรียม ยังไม่ใช่รอบดัน นับเมื่อดันขึ้นและกลับมาระดับไหล่
  ผู้ที่เริ่มจากท่าพร้อมดันระดับไหล่อยู่แล้วก็ยังใช้ได้

เผื่อองศา
- เมนูท่าดัมเบลและคาร์ดิโอเลือก 5,10,15,20,25,30,35,40,45,50° ได้
- ค่าเริ่มต้นยังเป็น 10°; ค่าสูงช่วยผ่อนเกณฑ์นับ แต่ไม่ได้ยกเลิกเกณฑ์ทิศทางหรือการมองเห็น
- ช่วงเริ่มและช่วงปลายยังแยกจากกัน และต้องเคลื่อนไหวผ่านช่วงขั้นต่ำ ป้องกันอยู่นิ่งแล้วได้แต้ม
- ค่าผ่อนผันเป็นค่าสูงสุดที่ขอใช้ ระบบจำกัดผลต่อแต่ละจุดปลายเพื่อไม่ให้เกณฑ์ทับกัน
  ดูมุมเริ่ม/มุมปลายจริงได้ในตารางเกณฑ์บนเว็บ
- คาร์ดิโอบันทึกค่าผ่อนผันกับแต่ละรอบและแยกอันดับตามค่าเดียวกัน ประวัติเก่าใช้ค่าเดิม 10°
- วิดพื้นยังไม่มี kcal ประมาณในรุ่นนี้; กราฟประวัติและเหรียญใช้ระบบเดิม

ทดสอบ
Python regression 222 tests ผ่าน และทดสอบการเก็บค่าผ่อนผัน/อันดับเพิ่มเติมอีก 1 รายการผ่าน รวม 223 tests
ทดสอบค่าข้อต่อหมุนกล้อง 0/30/60/90/-90° ของทุกท่าดัมเบล และลำดับวิดพื้น/โดดตบมุมหน้า–ข้าง
ทดสอบเตรียม Shoulder Press จากขาโดยไม่เพิ่มแต้ม เกณฑ์ 50° ไม่ทับกัน และท่าค้างไม่สร้างแต้ม
ทดสอบจำลองกล้องเปิด–ปิด 200 รอบต่อผู้ใช้ พร้อมตรวจแยกเซสชัน
เป็นการทดสอบพิกัดและกล้องจำลอง ยังไม่ได้ทดสอบกล้องจริงของผู้ใช้ทุกอุปกรณ์
