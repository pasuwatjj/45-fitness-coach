45 Fitness Coach — PATCH v30 สำหรับติดตั้งทับ v29

แพตช์นี้มีเฉพาะไฟล์ที่เปลี่ยน ไม่ใช่เว็บทั้งชุด ต้องมี v29 เดิมอยู่ก่อน
ไม่ต้องอัปโหลดฐานข้อมูลใหม่ และไม่ต้องลบโฟลเดอร์เดิม

วิธีอัปโหลดให้ถูกตำแหน่ง
1. หยุดและบันทึกเซตที่กำลังเล่น แล้วหยุดโปรแกรม Python/บริการเว็บชั่วคราว
2. สำรองโฟลเดอร์เว็บเดิม โดยเฉพาะ data และค่าตั้งส่วนตัวก่อนอัปเดต
3. แตก 45Fitness-PATCH-v30.zip แล้วเข้าโฟลเดอร์เว็บจริงที่มี app.py อยู่เดิม
   อัปโหลด/คัดลอกไฟล์จาก ZIP ทับตามชื่อและตำแหน่งเดิมดังรายการข้างล่าง
   ห้ามเอาไฟล์ทั้งหมดไปกองไว้ใน static หรือ templates และห้ามสร้างโฟลเดอร์เว็บซ้อนอีกชั้น

A. วางในโฟลเดอร์หลักของเว็บ ข้าง app.py เดิม:
   app.py

   localization.py
   sessions.py
   visitors.py

B. วางในโฟลเดอร์ templates:

ไฟล์ README_UPLOAD_V30_TH.txt, PATCH_MANIFEST_V30.json และ TEST_REPORT_V30.txt
เป็นคู่มือ/รายการตรวจสอบ จะเก็บข้าง app.py หรือเก็บไว้ในเครื่องก็ได้ ไม่จำเป็นต่อการรันเว็บ

4. เปิดบริการเว็บใหม่ด้วยคำสั่ง/ตัวเริ่มเดิมที่ใช้อยู่ เพื่อโหลด app.py และ Python modules ใหม่
5. เปิดเว็บแล้วกด Ctrl+Shift+R หรือปิดแท็บและเปิดใหม่บนมือถือ
   ไฟล์ CSS/JS ในหน้าเว็บใช้ ?v=30 เพื่อเปลี่ยนแคช ต้องอัปโหลด templates/index.html ด้วย
6. ตรวจว่า English เปลี่ยนเมนูและหน้าใช้งานเป็นอังกฤษ, My profile เปลี่ยนชื่อแล้วรีเฟรชยังอยู่,
   ไม่มีปุ่มกลับหน้าหลักในแถบบน แต่โลโก้และเมนู Home ยังกลับหน้าหลักได้

สิ่งที่เปลี่ยน
- แปลคำ/วลีเต็มโดยตรวจขอบเขตอักษรไทย ป้องกันการแทรก Chest กลางคำว่าออกกำลังกาย
- เพิ่มคำแปลเมนูที่ธีมสร้างใหม่ ปฏิทิน ข้อผิดพลาด และหน้าใช้งานแบบเปลี่ยนข้อมูลทันที
- บัญชีที่มีโปรไฟล์แล้วสร้างเพิ่มไม่ได้ แม้ส่งคำขอไปยังเซิร์ฟเวอร์โดยตรง
- เปลี่ยนชื่อได้ในโปรไฟล์ของฉัน ผ่านการตรวจเจ้าของ ชื่อใหม่ใช้ ID เดิม ประวัติจึงอยู่ครบ
- โปรไฟล์หลักใช้ ID ที่เก่าที่สุดอย่างคงที่ ไม่เปลี่ยนเพราะเรียงตามชื่อ
- บัญชีเก่าที่เคยมีหลายโปรไฟล์ยังเก็บทุก ID และประวัติเดิมไว้ เลือกดูข้อมูลเก่าได้;
  ไม่มีการลบหรือรวมข้อมูลอัตโนมัติ และเปลี่ยนชื่อได้เฉพาะโปรไฟล์หลัก
- ชื่อ VIP เป็นทองพร้อมแสง RGB เคลื่อนไหว; แอดมินใช้สีรุ้งเหนือ VIP
  ปิดการเคลื่อนไหวตามการตั้งค่า reduced motion ของอุปกรณ์
- จัดแถบปุ่มบนใหม่และแก้หน้าโปรไฟล์ล้นจอเล็ก

ข้อมูลที่แพตช์ไม่บรรจุและไม่ต้องเขียนทับ
data/, ฐานข้อมูล, .env, คีย์, รหัสผ่าน, SMTP, สลิป, ข้อมูลสมาชิก และข้อมูลการเล่นจริง
รูป/โมเดล/วิดีโอ v29 เดิมยังต้องเก็บไว้ แพตช์ไม่ได้บรรจุไฟล์เหล่านั้นซ้ำ
ไม่มีการเผยแพร่หรืออัปโหลดไปยังเซิร์ฟเวอร์จริงให้โดยอัตโนมัติ

หากต้องย้อนกลับ: หยุดบริการแล้วนำไฟล์โค้ดจากสำเนา v29 กลับมาทับตามเดิม
