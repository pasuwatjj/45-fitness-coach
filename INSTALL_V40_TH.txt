45 Fitness Coach V40 — อัปเดตจาก V38 หรือ V39

แพ็กนี้เป็นไฟล์แก้ไขสะสม ไม่ใช่เว็บใหม่ทั้งระบบ ต้องวางทับโปรเจกต์เดิม
มีไฟล์ระบบ 21 ไฟล์: ที่รากโปรเจกต์ และใน static, templates, models

วิธีติดตั้ง
1. สำรองโฟลเดอร์โปรเจกต์เดิมก่อน หยุดเซิร์ฟเวอร์เดิมด้วย Ctrl+C
2. แตก ZIP แล้วคัดลอกไฟล์ทั้งหมดตามโครงสร้างเดิม วางทับไฟล์ชื่อเดิม
   ไม่ต้องลบโฟลเดอร์เดิม ไม่ลบฐานข้อมูล .env รูป วิดีโอ หรือข้อมูลผู้ใช้
3. ถ้าใช้ GitHub ให้อัปโหลดไฟล์ที่ราก และไฟล์ภายใน static / templates / models
   ให้ครบทุกไฟล์ในแพ็กนี้ อย่าสร้างโฟลเดอร์ซ้อนเพิ่ม แล้วรอ Deploy สำเร็จ
4. เครื่อง Windows: เปิด PowerShell ในโฟลเดอร์โปรเจกต์ ใช้ environment เดิม
   แล้วรันคำสั่งเดิม หรือ python app.py
5. กด Ctrl+Shift+R บนคอมเพื่อโหลดไฟล์หน้าเว็บใหม่ บนมือถือปิดแท็บแล้วเปิดใหม่
   มือถือต้องใช้ลิงก์ HTTPS และอนุญาตกล้อง

สิ่งที่แก้
- ล็อกผู้เล่นครึ่งตัวได้แม้สะโพกอยู่นอกภาพ
- สลับจากตรวจจับฝั่งเซิร์ฟเวอร์เป็น Worker แล้วไม่ทำให้ล็อกเสียถาวร
- หลุดสั้น ๆ หยุดนับชั่วคราว และลองจับตำแหน่งเดิมใน 600 ms
  หลุดนานหรือมีคนซ้อนกันต้องเลือกผู้เล่นใหม่ ไม่ให้แต้มจากช่วงติดตามหาย
- เส้นและจุดข้อต่อเห็นชัด รวมการแก้จาก V39
- แสดงตัวละครเดิมของบัญชีที่สร้างไว้ มุมซ้ายบน เคลื่อนไหวตามจุดที่ตรวจพบ
- ช่องแสดง/ซ่อนตัวละครใกล้สลับแขนอัตโนมัติ และในหมวดคาร์ดิโอ
- ครึ่งตัวไม่เดาการเคลื่อนไหวขา วิดพื้นใช้ท่ารอแนวนอน
- หยุดกล้อง/ออกจากบัญชี/เล่นหลายคนจะซ่อนตัวละคร
- แก้หยุดคาร์ดิโอแล้วกลับมาเริ่มเวทไม่ได้จากข้อมูลสรุปที่ไม่มี tips

ตัวละครเป็นภาพแสดงผลเท่านั้น ไม่เปลี่ยนสูตรนับรอบ เหรียญ หรือการตัดสินฟอร์ม
ข้อมูลตัวละครอ่านจากบัญชีเดิม ไม่สร้างตัวละครแทนผู้ใช้
หากยังตรวจจับไม่ได้ กรุณาส่งข้อความ Console ที่เกิดเมื่อกดเปิดกล้อง
พร้อมรุ่นอุปกรณ์และเบราว์เซอร์ เพื่อแยกปัญหาเครื่องจริงจากชุดทดสอบ
