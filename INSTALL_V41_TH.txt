45 Fitness Coach V41 — แก้ตามตัวหลุดค้างและตัวละครกระตุก

ใช้วางทับโปรเจกต์เดิม V38 / V39 / V40 ได้ เป็นอัปเดตสะสม 21 ไฟล์
ไม่ใช่โปรเจกต์ใหม่แบบรันเดี่ยว ต้องมีไฟล์เว็บเดิมอยู่แล้ว

ติดตั้ง
1. สำรองโปรเจกต์เดิม แล้วหยุดตัวรันเดิมด้วย Ctrl+C
2. แตก ZIP คัดลอกไฟล์ระบบด้านนอกและไฟล์ภายใน static, templates, models
   วางทับตำแหน่งชื่อเดียวกันในโปรเจกต์เดิมให้ครบ ไม่วางโฟลเดอร์ซ้อน
3. ไม่ต้องลบฐานข้อมูล .env รูป วิดีโอ หรือโฟลเดอร์เดิม
4. ถ้าอัป GitHub ให้อัปไฟล์ตามตำแหน่งเดิมให้ครบ แล้วรอ Deploy สำเร็จ
5. PowerShell ใช้ environment เดิม เปิดในโฟลเดอร์โปรเจกต์แล้วรัน python app.py
   หรือใช้คำสั่งรันเดิมของคุณ
6. โหลดหน้าเว็บใหม่ Ctrl+Shift+R บนคอม มือถือปิดแท็บแล้วเปิดลิงก์ HTTPS ใหม่

สิ่งที่แก้จาก V40
- ยกเลิกอาการโหมดคนเดียวหลุดเกิน 600 ms แล้วค้างรอเลือกใหม่ตลอด
- เมื่อเห็นคนใกล้ตำแหน่งเดิมต่อเนื่องอย่างน้อย 3 ภาพและ 200 ms จะตามใหม่
  ระหว่างรอยังไม่ส่งข้อมูลเข้าไปนับ ไม่ต้องปิดเปิดกล้องใหม่
- รักษาเซตและรอบที่นับสำเร็จไว้ ล้างเฉพาะรอบที่ยังทำไม่ครบเมื่อการตามตัวหาย
- ถ้าคนซ้อนกันยังหยุดและให้เลือกใหม่ ไม่อาศัยลำดับคนที่โมเดลคืนมา
- ลดอาการสั่นจากค่าความมั่นใจใกล้จุดตัดด้วยเกณฑ์ต่อเนื่องที่ต่างจากเกณฑ์เริ่มจับ
- ค้างเส้นเดิมได้สั้น ๆ ไม่เกิน 250 ms เฉพาะภาพแสดงผลขณะข้อมูลขาด
- ตัวละครใช้การผสมท่าต่อเนื่องระยะสั้น และเก็บท่าล่าสุดไม่เกิน 350 ms
  หลังข้อมูลท่าหมดอายุ จากนั้นกลับท่ารอ ไม่แสร้งเคลื่อนไหวเมื่อไม่มีข้อมูล
- การหน่วง/ผสมท่าตัวละครไม่ได้ใช้คำนวณมุม ฟอร์ม เหรียญ หรือรอบ
- การหยุดกล้อง เปลี่ยนเซต เปลี่ยนบัญชี คนซ้อนกัน ล้างภาพเก่าตามขอบเขต

คงระบบตัวละครของบัญชีเดิม ปุ่มแสดง/ซ่อน เวท คาร์ดิโอ และระบบเว็บเดิมไว้
ระบบตามตำแหน่งไม่ใช่การยืนยันตัวตนด้วยใบหน้า หากคนอื่นมาแทนตำแหน่งเดียวกัน
กล้องเดี่ยวไม่สามารถรับประกันว่าเป็นคนเดิมได้

หากอัปครบแล้วยังผิดปกติ ส่งภาพ Console (F12 > Console) ขณะเปิดกล้อง
พร้อมรุ่นอุปกรณ์และเบราว์เซอร์ เพื่อหาปัญหาเฉพาะเครื่องต่อ
