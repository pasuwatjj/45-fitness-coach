45 Fitness Coach — v27 ปรับหน้าจอให้กดง่ายและดูโล่งขึ้น
อัปเดต 24 ตุลาคม 2026

สิ่งที่เปลี่ยน
• ซ่อน 3 การ์ดข้างกล้อง: เพื่อนช่วยสังเกต, มุมศอกโดยประมาณ และสิ่งที่กำลังช่วยดู
  ตัวนับครั้งหลักยังอยู่ กล้องมีพื้นที่กว้างขึ้น และไม่เหลือช่องการ์ดว่างบนมือถือ
  เก็บองค์ประกอบข้อมูลไว้ให้ระบบนับครั้งและอัปเดตสถานะทำงานต่อได้ตามเดิม
• ซ่อนปุ่ม “รีเฟรชเว็บ” บนแถบบัญชี ใช้โลโก้กลับหน้าหลักได้ตามเดิม
  ปุ่ม “รีเซ็ตกล้อง / Reset camera” ยังอยู่
• ขยายเมนูหลักทั้ง 6 ให้เต็มความกว้างและกดง่ายขึ้น
  จอใหญ่ 6 คอลัมน์, จอกลาง 3 คอลัมน์, มือถือขนาดเล็ก 2 คอลัมน์
• คงธีมทั้งสอง ภาษาไทย/อังกฤษ และความสามารถของ v26

วิธีอัปเดตจาก v26
1. แตก ZIP แล้วเข้าโฟลเดอร์ 45Fitness-Ready-v27
2. นำไฟล์และโฟลเดอร์ข้างในแทนที่ราก repository เดิม อย่าซ้อนโฟลเดอร์ v27 อีกชั้น
   ZIP เป็นโครงการครบชุด รวม static/, templates/, models/ และไฟล์ Python ของ v26
   ไฟล์ที่ปรับในรุ่นนี้: app.py, templates/index.html และ static/v27.css
3. คงฐานข้อมูล ดิสก์ /data และ Environment เดิม ไม่ต้องลบข้อมูลหรือสร้างบัญชีใหม่
   ZIP นี้ไม่รวมฐานข้อมูลผู้ใช้ ไฟล์ตั้งค่าลับ หรือแคช
4. Commit แล้วสั่ง Deploy latest commit ใน Render ตามขั้นตอนเดิม
   หน้าเว็บโหลด CSS ใหม่ผ่าน /static/v27.css?v=27
   หากยังเห็นหน้าจอเดิม ให้โหลดหน้าใหม่แบบไม่ใช้แคชด้วย Ctrl+Shift+R หนึ่งครั้ง

หากใช้งานบนคอมส่วนตัว ให้หยุดโปรแกรมก่อนแทนไฟล์ แล้วเปิดด้วยวิธีเดิม
ไม่ใช้ Install-Update.ps1 สำหรับรุ่นนี้ เพราะสคริปต์นั้นเป็นตัวอัปเดตเก่า v24
รายละเอียดการตั้งค่าระบบและความสามารถ v26 ดู DEPLOY_V26_TH.txt
แพ็กเกจนี้ยังไม่ได้อัปโหลดไป GitHub หรือ Deploy ให้
