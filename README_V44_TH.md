# 45 Fitness Coach — V44 Avatar Studio & Daily Exercise Energy

อัปเดตวันที่ 30 ตุลาคม 2026 สำหรับทีม 45 Fitness Coach

**ชุดนี้เป็น cumulative update ต่อจาก V42/V43 สำหรับทับในโปรเจกต์เดิม ไม่ใช่ซอร์สฐานทั้งระบบและไม่ใช่เว็บที่เปิดด้วย GitHub Pages ได้** ผู้ใช้เลือกให้ดำเนินการจากแพตช์ที่มี จึงรักษา Python/Flask และระบบเดิมไว้ ไม่สร้างระบบบัญชีใหม่มาแทน

## สิ่งที่เปลี่ยน

- เปลี่ยนตัวละครหลักเป็นโมเดลสามมิติผิวโค้งด้วย Three.js มีโครงลำตัว ไหล่ แขน ขา มือ นิ้ว เท้า ใบหน้า ผมและกางเกง หมุนดูได้รอบตัว
- อิงภาพตัวอย่างในด้านสัดส่วนและแนวการ์ตูน มีรูปร่างผอม กำยำ และอวบ โมเดลสร้างจากโค้ดต้นฉบับ ไม่ได้ดึงไฟล์โมเดลเชิงพาณิชย์จากภาพมาใช้ และไม่ได้อ้างว่ารายละเอียดเทียบเท่าโมเดลปั้นในภาพ
- ใช้ความสัมพันธ์น้ำหนัก/ส่วนสูงปรับความอวบโดยประมาณ และให้เลือกความกำยำเพื่อความสวยงามแยกจากข้อมูลสุขภาพ กล้ามเนื้อจาก LV/EXP ยังเพิ่มได้อย่างจำกัดในเชิงเกม
- เลือกตา 3 แบบ จมูก 3 แบบ ใบหน้า 2 แบบ ผม 6 แบบ สีตา สีผิว สีผม สีกางเกง บันทึกผ่านบัญชีเดิม ข้อมูลตัวละครเก่ายังอ่านได้
- ตัวละครระหว่างออกกำลังกายยังใช้ pose rig เดิม ขนาด 60–220% จาก V43 ยังอยู่
- เพิ่มการ์ดพลังงานในหน้าโปรไฟล์: พลังงานเพิ่มจากการออกกำลัง, พลังงานรวมช่วงออกกำลัง, เวลาการเคลื่อนไหว, รายการแยกกิจกรรม และเลือกวันย้อนหลัง
- รวมเวททุกท่าที่ผ่านช่องรับภาพเดิม และคาร์ดิโอ full / upper / pushup; ไม่ผูกแคลอรี่กับจำนวนครั้งที่ผ่านฟอร์ม เพราะการเคลื่อนไหวที่ไม่ผ่านก็ยังใช้พลังงาน
- วันแบ่งที่เที่ยงคืน Asia/Bangkok, น้ำหนักถูกเก็บ ณ จุดเริ่มช่วงกิจกรรม, เขียนยอดแบบ idempotent เพื่อไม่เพิ่มซ้ำเมื่อกดพัก/รีเฟรช
- โหมดสองคนยังไม่บันทึกตามพฤติกรรมเดิม ข้อมูลที่ตรวจจับไม่ได้หรือไม่มีน้ำหนักจะไม่ถูกเดาเติม

## ติดตั้งแบบแนะนำ

1. หยุดเซิร์ฟเวอร์เดิม สำรองโฟลเดอร์โปรเจกต์และฐานข้อมูลของคุณ
2. แตก ZIP นี้ไว้อีกโฟลเดอร์หนึ่ง อย่าเปิด `app.py` ในโฟลเดอร์แพตช์โดยตรง
3. ตรวจความเข้ากันได้จากโฟลเดอร์แพตช์:

   ```bash
   python tools/apply_v44.py "PATH_TO_EXISTING_PROJECT" --check
   ```

4. หากตรวจผ่าน ให้ติดตั้ง:

   ```bash
   python tools/apply_v44.py "PATH_TO_EXISTING_PROJECT"
   ```

5. เปิดเซิร์ฟเวอร์ตามวิธีเดิม เช่น `python app.py` ในโฟลเดอร์โปรเจกต์จริง แล้วรีเฟรชแบบล้างแคช (`Ctrl+Shift+R`)
6. เข้าเมนูตัวละคร กรอกส่วนสูง/น้ำหนักและบันทึก จากนั้นเริ่มการออกกำลังกายใหม่ เปิดหน้าโปรไฟล์เพื่อดูยอดประจำวัน

ตัวติดตั้งตรวจ hash ของไฟล์ฐาน V42/V43 ก่อนเขียน หากพบไฟล์ที่แก้ต่างไปจะหยุดโดยยังไม่เปลี่ยนไฟล์ ให้ merge ความเปลี่ยนแปลงด้วยตนเอง ไม่ควรบังคับทับไฟล์ที่มีงานใหม่กว่า ตัวติดตั้งสำรองเฉพาะซอร์สที่ถูกแทนที่ไว้ข้างโฟลเดอร์โปรเจกต์ ไม่สำรองฐานข้อมูลให้อัตโนมัติ

## อัปขึ้น GitHub

ใช้ repository เดิมของเว็บที่มีซอร์สฐานอยู่แล้ว ชุดนี้ไม่ได้สร้างหรือ push repository ให้

- ทางสะดวก: ติดตั้งแพตช์ใน checkout เดิมตามขั้นตอนด้านบน ตรวจ diff แล้ว commit ไฟล์ที่เปลี่ยนและเพิ่ม
- ทาง Upload files: แตก ZIP แล้วนำ `app.py`, `character.py`, `activity_energy.py`, `static/`, `templates/`, `models/` ไปวางที่ root ของ repository เดิม โดยรักษาเส้นทางเดิม อย่าอัปทั้งโฟลเดอร์แพตช์ซ้อนเข้าไปอีกชั้น และตรวจว่าฐานเป็น V42/V43 ก่อน
- อัป `tests/`, `docs/`, `tools/`, `MANIFEST_V44.json`, `README_V44_TH.md` และ `TEST_REPORT_V44.md` ด้วยได้ เพื่อให้ทีมตรวจสอบและทดสอบต่อ
- ไม่ต้องอัปฐานข้อมูลจริง, `.env`, secret, cookie, ไฟล์บัญชีผู้ใช้, รูปส่วนตัว หรือโฟลเดอร์สำรอง
- GitHub ใช้เก็บซอร์ส ส่วนแอป Flask ต้องรันบนเครื่องหรือโฮสต์ที่รองรับ Python เช่นเดิม การอัปไฟล์อย่างเดียวไม่ได้ทำให้ Python รันบน GitHub Pages

ไม่เพิ่ม dependency ฝั่ง Python ในส่วนใหม่ Three.js และ license อยู่ใน `static/vendor/` แล้ว ไม่ต้องโหลด CDN ตอนใช้งานตัวละคร

## วิธีประมาณแคลอรี่

ใช้ MET จาก Adult Compendium 2024:

| กิจกรรมในแอป | MET | รหัส | หมายเหตุ |
|---|---:|---|---|
| เวททุกท่า | 3.5 | 02054 | ค่าเริ่มต้นของการฝึกแรงต้านทั่วไป ไม่เท่ากับความหนักที่วัดจริง |
| กระโดดตบเต็มตัว | 7.5 | 02020 | ค่า vigorous calisthenics เป็นสมมติฐานของกิจกรรม ไม่ใช่การยืนยันความหนักรายคน |
| คาร์ดิโอช่วงบน | 3.5 | 02030 | ใช้ general light/moderate เป็นค่าประมาณแทนกิจกรรมเฉพาะ |
| วิดพื้น | 3.8 | 02022 | moderate calisthenics |

`gross kcal = MET × 3.5 × น้ำหนัก(kg) ÷ 200 × นาที`

`active kcal = max(MET − 1, 0) × 3.5 × น้ำหนัก(kg) ÷ 200 × นาที`

ใช้เวลาระหว่างเฟรมจากนาฬิกาเซิร์ฟเวอร์ เฉพาะช่วงมี landmark ต่อเนื่องและมีแขน/ขาเคลื่อนเทียบกับไหล่ ไม่ใช่เวลาตั้งแต่เปิดกล้องจนปิดทั้งหมด ช่องว่างเกิน 1 วินาที, ช่วงพัก, คนหาย, โหมดสองคน จะไม่นำมารวม บันทึกทุกประมาณ 10 วินาทีและตอนพัก/ปิด/เปิดดูยอด

**ตัวเลขเป็นค่าประมาณของช่วงการเคลื่อนไหวที่ติดตามได้ ไม่ใช่ TDEE ไม่ใช่ผลวัด metabolic calorimetry และไม่รับประกันแคลอรี่จริงรายคน** เกณฑ์ motion อาจพลาดท่าช้า ท่าค้าง หรือได้รับผลจากกล้องสั่น; ค่า MET ทั่วไปมีข้อจำกัดตามอายุ สมรรถภาพ และความหนัก ส่วนนี้ยังไม่ได้ทำการทดลองเทียบเครื่องวัดจริง

ไม่คำนวณประวัติเก่าจากจำนวนครั้งล้วน ๆ เพราะไม่มีเวลาที่เชื่อถือได้ หากไม่มีน้ำหนัก จะเก็บเวลาพร้อมแจ้งว่าช่วงนั้นยังไม่รวมแคลอรี่ การแก้น้ำหนักภายหลังไม่เขียนทับน้ำหนักของกิจกรรมก่อนหน้า ถ้าเซิร์ฟเวอร์ดับฉับพลันอาจสูญเสียเวลาล่าสุดก่อนรอบบันทึก

## ข้อมูลและการเข้าถึง

- ตัวเลือกใหม่อยู่ใน JSON ตาราง `game_characters` เดิม และใช้ `profile_dimensions` เดิม
- พลังงานอยู่ในตารางใหม่ `activity_energy_v44` ไม่แก้จำนวนครั้ง เหรียญ คะแนน หรือตารางเก่า
- endpoint `/profiles/<id>/energy` ผ่าน guard เซสชันและเจ้าของโปรไฟล์เดิม ไม่เปิดข้อมูลสุขภาพของผู้อื่น
- reset analytics ล้างพลังงานด้วย พร้อมทิ้ง meter ที่ค้างอยู่; ลบโปรไฟล์ล้างพลังงานผ่าน SQLite trigger
- หลังติดตั้งใหม่ที่ยังไม่มีข้อมูล จะแสดงว่าไม่มีเวลาที่บันทึก ไม่สร้างข้อมูลสาธิตในบัญชีจริง
