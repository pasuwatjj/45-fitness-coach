อัปเดต
1. ดาวน์โหลด FitnessFormCoach_Update.zip ใหม่ไปไว้ D:\Robot Project
2. ปิดแท็บเว็บ กด Ctrl+C ในหน้าต่างเว็บและแชร์ลิงก์ ถ้าใช้โหมดเบื้องหลัง ให้รัน Stop-AlwaysOn.ps1 ก่อน
3. เปิด UPDATE_POWERSHELL.txt แล้วคัดลอกบล็อกคำสั่งไปรัน คำสั่ง Expand-Archive แตก ZIP ให้อัตโนมัติ ไม่ต้องแตก ZIP เก่าทีละไฟล์
4. ตัวติดตั้งสำรองโค้ดเดิมไว้ backup-วันเวลา แล้วอัปเดตโปรเจกต์ ข้อมูลใน data ไม่ถูกแทนที่
5. เปิด http://127.0.0.1:5000/45-fitness-coach แล้ว Ctrl+F5
6. สำหรับมือถือ เปิด PowerShell อีกหน้าต่าง รัน Start-Share.ps1 ใช้ลิงก์ HTTPS ใหม่ที่แสดง

กล้อง
- ทุกครั้งที่เริ่ม ระบบบันทึก/ล้างสถานะเซสชันของแท็บเดิม สร้างตัวประมวลผลใหม่ แล้วเปิดกล้อง
- สร้าง video element ใหม่ ตัด event เก่า และแยกผลเฟรมเก่าจากรอบใหม่
- กด รีเซ็ตกล้อง แล้วกด เปิดกล้อง ได้โดยไม่ต้องปิด Python
- ปุ่มรีเซ็ตเป็นของแท็บที่กดเท่านั้นและบันทึกเซตก่อน ถ้าบันทึกไม่สำเร็จจะไม่ล้างข้อมูลเซต
- คำสั่ง PowerShell สำรอง: powershell -NoProfile -ExecutionPolicy Bypass -File .\Reset-Camera.ps1
  คำสั่งนี้รันที่โฟลเดอร์โปรเจกต์ รีเซ็ตกล้องของทุกเซสชันบนเซิร์ฟเวอร์ จึงใช้เมื่อผู้เล่นอื่นหยุดแล้ว
- ถ้ายังเปิดไม่ได้ ถ่ายข้อความผิดพลาดที่ค้างบนหน้าเว็บ ปุ่มรีเซ็ตไม่ได้แก้สิทธิ์กล้องที่ถูกปฏิเสธหรือกล้องเสีย

คลิป
- arm.mp4 อยู่ใต้รูปใน Dumbbell Biceps Curl
- chest.mp4 อยู่ใต้รูปใน Dumbbell Floor Press
- shoulder.mp4 อยู่ใต้รูปใน Dumbbell Shoulder Press
- leg.mp4 อยู่ใต้รูปใน Dumbbell Goblet Squat
- คลิปเป็นชุดสอนประจำหมวด ใส่ไว้ที่ท่าแรกตามที่ขอ รองรับเลื่อนเวลาและมือถือ ไม่เล่นอัตโนมัติ
- หมวดหลังยังไม่มีไฟล์คลิปที่ส่งมา

แอดมิน
- ตัวติดตั้งเรียก Setup-Admin.ps1 ให้บัญชีที่มีอยู่แล้ว: admin@example.com
- จะไม่สร้างบัญชีหรือให้ยศอัตโนมัติแก่ผู้ที่มาสมัครอีเมลนี้ในอนาคต
- ถ้าหาบัญชีไม่พบ ให้เข้าสู่บัญชีเดิมบนเว็บที่คอม แล้วรัน Setup-Admin.ps1 จากโปรเจกต์อีกครั้ง
- รีเฟรชเว็บ จะเห็น 🛡 ADMIN และปุ่ม หลังบ้าน
- หลังบ้านค้นหาอีเมล ดูโปรไฟล์/ประวัติและสุขภาพ ให้ VIP 30 วัน และดูสลิปเพื่ออนุมัติได้
- API ตรวจสิทธิ์แอดมินที่เซิร์ฟเวอร์ บัญชีธรรมดาเปิด URL หลังบ้านไม่ได้

VIP ที่โอนแล้ว
- อย่าโอนซ้ำ สลิปเดิมยังอยู่ในฐานข้อมูลเดิม
- ถ้าบริการตรวจอัตโนมัติยังไม่พร้อม สลิปจะเป็น review ต้องให้แอดมินอนุมัติ
- หลังบ้าน > สลิป > ดูสลิป ตรวจรายการเงินเข้าจริงในบัญชีธนาคาร
- กรอกเลขอ้างอิงธนาคารรูปแบบ 004:เลขอ้างอิง แล้วกด ตรวจเงินจริงแล้ว · อนุมัติ VIP
- หรือแอดมินให้ VIP 30 วันจากรายการสมาชิกโดยตรงได้ เป็นการให้สิทธิ์โดยผู้ดูแล ไม่ใช่การยืนยันสลิป
- เมื่ออนุมัติแล้ว ผู้รับกดหน้า VIP เพื่อรีเฟรชสถานะ มีตรา VIP ที่ปุ่มโปรไฟล์และในหน้าโปรไฟล์
- หากแอดมินกำลังกดให้สิทธิ์ตนเอง หน้าเว็บจะรีเฟรชสถานะให้ทันที
- การให้สิทธิ์ด้วยคำขอเดิมหรืออนุมัติสลิปเดิมซ้ำไม่เพิ่มวันซ้ำ
- แก้เพดานรับข้อมูลภาพเดิม 1 MB ให้ตรงกับสลิปสูงสุด 5 MB
- อีเมลแจ้งสลิปยังต้องตั้ง SMTP ที่ใช้งานได้ ยศจากผู้ดูแลใช้ได้แม้อีเมลยังตั้งไม่เสร็จ

เพื่อน
- ผู้สมัครบัญชีเห็นปุ่ม เพื่อน ค้นหาชื่อ ดูโปรไฟล์ ส่งคำขอ ตอบรับ และลบเพื่อนได้
- ผู้รับเท่านั้นที่ตอบรับคำขอได้
- สมาชิกอื่นเห็นชื่อ รูป จำนวนครั้ง เซต และไฟ ข้อมูลสุขภาพ อีเมล สลิปไม่แสดงในโปรไฟล์สาธารณะ
- แอดมินเข้าดูข้อมูลบัญชีและโปรไฟล์ได้ตามสิทธิ์ดูแลระบบที่กำหนด

รันต่อเนื่อง
- ปิดเซิร์ฟเวอร์รอบปกติด้วย Ctrl+C ก่อน แล้วรัน Start-AlwaysOn.ps1
- ปิดหน้าต่างเริ่มรันได้ ตัวเว็บอยู่เบื้องหลังและลองเริ่มใหม่เมื่อโปรแกรมล้ม
- ปิดด้วย Stop-AlwaysOn.ps1 คอมต้องเปิด ไม่ Sleep และต่ออินเทอร์เน็ตตลอด
- Start-Share.ps1 ยังต้องเปิดค้างในอีกหน้าต่าง ลิงก์ชั่วคราวเปลี่ยนเมื่อเริ่มใหม่
- เปิดเว็บได้แม้ปิดคอมต้องย้ายไปโฮสต์ อ่าน HOSTING_README_TH.txt
