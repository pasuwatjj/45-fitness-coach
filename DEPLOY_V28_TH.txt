45 Fitness Coach — v28 (24 ตุลาคม 2026)
ชุดพร้อมอัปโหลดทั้งโครงการ ไม่ต้องติดตั้ง v27 ก่อน
ยังไม่ได้อัปโหลด GitHub หรือ Deploy Render ให้

อาการที่แก้และสิ่งที่เปลี่ยน
• คืนขนาดเมนูและสัดส่วนกล้อง/แถบด้านข้างเหมือน v26 ไม่มีเมนูแบบ 6 ช่องขยายของ v27
• เอาดัมเบลตกแต่งใต้โลโก้ ปุ่มหยุดขยับ และปุ่มรีเฟรชเว็บออกจากหน้าจอ
  โลโก้ยังพากลับหน้าหลัก และปุ่มรีเซ็ตกล้องยังอยู่
• ซ่อนการ์ดเพื่อนช่วยสังเกต มุมศอกโดยประมาณ และสิ่งที่กำลังช่วยดู
  เก็บ DOM/ID ที่ระบบประมวลผลใช้ไว้ จึงยังอัปเดตสถานะกล้องได้
• ซ่อนกล่องคำแนะนำตัวใหญ่ด้านนอกกล้อง รวมทั้งปุ่มโหมดอ่านไกลและเปิด/ปิดเสียงเดิม
  ข้อความคำแนะนำที่ซ้อนในภาพกล้องยังอยู่
• ตั้งค่าเสียงอยู่ในหัวข้อเล็ก “ตั้งค่าเสียง / Voice settings” เหนือกล้อง
  ติ๊ก “เปิดเสียงโค้ชและเสียงนับครั้ง” เพื่อยินยอมเปิดเสียง หรือกด “ลองฟังเสียง”
  ปุ่มลองฟังเปิดเสียงและอ่านตัวอย่างให้เอง ตัวเลือกอ่านคำแนะนำ/เสียงนับครั้ง/ความเร็ว/ผู้ให้เสียงยังอยู่
  เสียงจะใช้เฉพาะผู้ให้เสียงที่เลือก หากบริการไม่พร้อมจะแสดงข้อความ ไม่เรียกเสียงอื่นทับ
  เมื่อโหลดหน้าใหม่ให้เปิดเสียงอีกครั้งตามข้อกำหนดการเล่นเสียงของเบราว์เซอร์
• หน้าของรางวัลรองรับโปรไฟล์ยังไม่มา รายการว่าง ข้อมูลไม่ครบ และเครือข่ายล้มเหลว
  มีข้อความอธิบาย ปุ่มโหลดใหม่ และทางไปสร้างโปรไฟล์/สมัคร VIP ไม่ปล่อยเป็นหัวข้อกับช่องว่าง
  ทุกบัญชีที่เข้าสู่ระบบยังแลกเหรียญฝึกเป็นสากลได้ ส่วนแลกเวย์ต้อง VIP เช่นเดิม
• หน้าสมัคร VIP แสดง QR และการแนบสลิปสำหรับบัญชีที่ยังไม่เป็น VIP
  หากโหลดสถานะหรือภาพ QR ไม่สำเร็จมีข้อความและปุ่มลองใหม่ การเปิด VIP/ตรวจสลิปยังใช้ระบบเดิม
• ตัวละครเปิดได้จากปุ่มบนแถบบัญชี หน้าหลัก โปรไฟล์ตัวเอง และโปรไฟล์สมาชิก
  ลิงก์ตรงใช้ /45-fitness-coach#character (หรือ #rewards / #vip / #profile)
  รูปลักษณ์บันทึกกับบัญชีอีเมลเดิม ไม่แชร์กับผู้เยี่ยมชมหรืออีเมลอื่น
  ตัวละครในหน้าแต่งตัวและภาพตัวอย่างในโปรไฟล์ตัวเอง/สมาชิกยกดัมเบลขึ้นลง
  แขน อก หลัง ไหล่ ขา ยังโตจากประวัติที่บันทึกของแต่ละโปรไฟล์ตามกติกา v26
  หยุดเฟรมเมื่อออกจากหน้า พ้นจอ ซ่อนแท็บ หรือเปิดกล้อง; เคารพ Reduce motion ของอุปกรณ์

สาเหตุที่ตรวจพบ
ภาพที่มีหัวข้อของรางวัลใหม่ แต่ยังมีปุ่มรีเฟรชเก่าและไม่มีปุ่มตัวละคร สอดคล้องกับไฟล์ HTML/JS คนละรุ่น
โค้ดเมนูเดิมเรียก characterPage/characterTab โดยไม่ตรวจว่ามีอยู่ เมื่อไฟล์ HTML เก่าขาดองค์ประกอบนี้
การเปลี่ยนหน้าจะหยุดก่อนโหลดข้อมูลของรางวัล/VIP ได้จริง จึงเกิดหน้าว่างโดยไม่มีข้อความหน้าเว็บ
v28 แก้การเปลี่ยนหน้าให้ทนต่อองค์ประกอบอื่นที่หาย มีข้อความแจ้งไฟล์ไม่ครบ และปรับ URL JS/CSS ทุกไฟล์เป็น ?v=28
นอกจากนี้ยังแก้กรณีโปรไฟล์ว่าง/เครือข่ายผิดพลาดแยกต่างหาก ไม่ได้สรุปว่าทุกอาการเกิดจากการ Deploy เพียงอย่างเดียว

วิธีอัปเดตจาก v26 หรือ v27 บน GitHub / Render
1. แตก ZIP แล้วเปิดโฟลเดอร์ 45Fitness-Ready-v28
   อัปโหลดไฟล์และโฟลเดอร์ “ข้างใน” ไปแทนที่ราก repository เดิมทั้งหมด
   app.py, serve.py, Dockerfile, requirements.txt, templates/, static/, models/ ต้องอยู่ระดับเดียวกัน
   อย่าซ้อนโฟลเดอร์ 45Fitness-Ready-v28 อีกชั้น และอย่าอัปโหลดเฉพาะ app.py
   ต้องรวม character.py, training_economy.py, training_modes.py และโมดูลเดิมทั้งหมด
   ไฟล์ใหม่สำคัญ: static/v28.css และ static/navigation-v28.js
   static/character.js, static/character-renderer.js, static/profile.js, static/rewards.js,
   static/vip.js, static/home.js, static/app.js และ templates/index.html ต้องมาจาก ZIP ชุดเดียวกัน
2. คงฐานข้อมูลและ Environment เดิม ไม่ต้องสมัครบัญชีใหม่ ไม่ลบดิสก์เดิม
   FITNESS_DATA_PATH=/data/fitness.db และ Render Disk Mount path /data ตามการตั้งค่าเดิม
   FITNESS_PUBLIC_URL=https://four5-fitness-coach.onrender.com ตามเดิม
   รหัสลับ/API key/SMTP/SlipOK/สิทธิ์แอดมินใช้ค่าเดิม ZIP ไม่ได้แนบไฟล์ลับหรือฐานข้อมูล
   สำรอง SQLite ให้สอดคล้องก่อนอัปเดต; อย่าคัดลอกเพียงไฟล์ .db ขณะกำลังมีการเขียน WAL
3. Commit แล้ว Render > Manual Deploy > Deploy latest commit รอ Live
   ใช้ Dockerfile และ python serve.py โปรเซสเดียวตามเดิม
   หากรันคอมส่วนตัว ให้ปิดโปรแกรมก่อนแทนไฟล์ แล้วเปิดด้วยวิธีเดิม
   ไม่ใช้ Install-Update.ps1 ซึ่งเป็นตัวอัปเดตรุ่นเก่า
4. เปิด /45-fitness-coach แล้ว Ctrl+Shift+R หนึ่งครั้ง
   ตรวจ View source ว่า JS/CSS ทุกไฟล์ลงท้าย ?v=28 และมี navigation-v28.js / v28.css
   ไม่ควรมีข้อความ “ไฟล์เว็บไม่ครบหรือคนละรุ่น”
5. เข้าบัญชีเดิม ตรวจ “ตัวละครของฉัน”, “แลกของรางวัล”, “สมัคร VIP Home”
   หน้า VIP ต้องเห็นภาพ QR จริง ถ้าไม่เห็นให้ตรวจ static/images/store/payment-qr.png ว่าอัปโหลดครบ
   หากหน้าเหรียญไม่มีชื่อ ให้กดลองโหลดอีกครั้ง หรือเปิดหน้าโปรไฟล์เพื่อเลือก/สร้างชื่อ
   ทดสอบเปิดกล้องเอง 1 เซต และเปิดตั้งค่าเสียง > ลองฟังบนอุปกรณ์ที่จะใช้จริง
