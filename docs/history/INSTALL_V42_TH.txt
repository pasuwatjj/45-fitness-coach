45 Fitness Coach V42 — กลับเข้ากล้อง / มุมข้าง / จุดกระโดด

แพ็กอัปเดตสะสม 23 ไฟล์ สำหรับโปรเจกต์เดิม V38–V41
ไม่ใช่โปรเจกต์ใหม่แบบรันเดี่ยว

ติดตั้ง
1. สำรองโปรเจกต์และหยุดตัวรันเดิม (Ctrl+C)
2. แตก ZIP วางไฟล์ด้านนอกทับที่รากโปรเจกต์ และวางไฟล์ภายใน
   static / templates / models ลงในโฟลเดอร์ชื่อเดียวกันให้ครบ
   มีไฟล์ใหม่สำคัญ: pose_sanity.py และ static/pose-stability.js
3. ไม่ต้องลบฐานข้อมูล .env รูป คลิป หรือโฟลเดอร์เดิม
4. GitHub: อัปโหลดทุกไฟล์ในแพ็กตามตำแหน่งเดิม แล้วรอ Deploy สำเร็จ
5. PowerShell: ใช้ environment เดิม เปิดในโฟลเดอร์โปรเจกต์แล้ว python app.py
   หรือใช้คำสั่งรันเดิมของคุณ
6. คอมกด Ctrl+Shift+R มือถือปิดแท็บแล้วเปิด HTTPS ใหม่

การใช้งาน
- เวทเลือก Full เป็นค่าเริ่มต้นใหม่; เปลี่ยน Lite ได้หากเครื่องประมวลผลช้า
- ปุ่ม จับตำแหน่งใหม่ อยู่ในภาพกล้อง ใช้ได้ในโหมดคนเดียว
  ไม่เปิดกล้องใหม่ ไม่ล้างเซตหรือรอบที่นับสำเร็จ แต่ยกเลิกรอบที่ยังทำไม่ครบ
- เปิดกล้องแล้วไม่เห็นคนทันที ระบบยังค้นหาต่อ
- หลังหลุดหรือสับสน หากเหลือคนเดียวที่เห็นชัดต่อเนื่องอย่างน้อย 4 ภาพ
  และ 650 ms จะจับคนเดียวที่เห็นได้ใหม่ แม้กลับมาคนละตำแหน่ง
- มีหลายคนยังใช้การเลือกผู้เล่น ไม่สุ่มนับจากลำดับที่โมเดลส่งมา

การปรับตำแหน่ง/คุณภาพ
- Full สำหรับเวท และภาพเข้าได้ถึงด้านยาว 960 px โดยไม่ขยายภาพต้นฉบับที่เล็กกว่า
- เพิ่มจุดใกล้ศีรษะร่วมกับไหล่สำหรับช่วยจับตำแหน่งเมื่อหันข้าง
  จุดเหล่านี้ไม่ใช่มุมที่เอาไปนับรอบ
- ตรวจจุดไหล่ ศอก สะโพกที่กระโดดโดดเดี่ยวและสัดส่วนเส้นเปลี่ยนผิดปกติ
  พักข้อมูลจุดนั้นก่อน ไม่บังคับให้ศอกนิ่ง ไม่ลากสะโพกไปตำแหน่งที่เดา
- กรองภาพเส้นและตัวละครให้เคลื่อนไหวต่อเนื่องขึ้น; server ตรวจคุณภาพ
  แยกก่อนใช้ข้อมูลดิบคำนวณ จึงไม่เอาภาพที่ค้างมานับเป็นรอบ
- จุดสะโพกความมั่นใจต่ำจะไม่วาดเป็นเส้นทึบให้ดูแน่นอนเกินข้อมูล
- Worker ลองสร้างตัวตรวจจับใหม่เป็นช่วง ๆ เมื่อไม่พบคนต่อเนื่อง
  และมี timeout ขณะเตรียมภาพ เพื่อไม่รอค้างไม่สิ้นสุด

ข้อจำกัด
ระบบจับตำแหน่งเชิงพื้นที่ ไม่ใช่การยืนยันใบหน้า หากคนอื่นมายืนแทนคนเดียว
ระบบอาจจับคนนั้นได้ การกรองลดจุดกระโดดชั่วคราว แต่แก้ตำแหน่งที่โมเดล
ทำนายผิดอย่างต่อเนื่องให้ถูกทางกายวิภาคไม่ได้ จุด 23/24 ของโมเดลคือสะโพก
ไม่ใช่แนวเอวกางเกง จึงไม่ได้บังคับตำแหน่งตามขอบเสื้อหรือกางเกง
Full อาจช้ากว่า Lite บนมือถือ ให้เลือกตามอุปกรณ์

ถ้ายังมีปัญหา ส่งวิดีโอหน้าจอสั้น ๆ ที่เห็นอาการและ Console (F12)
พร้อมรุ่นเครื่อง/เบราว์เซอร์ ข้อมูลนี้จำเป็นเพื่อแยกจุดผิดจากโมเดลกับระบบวาด
