45 Fitness Coach PATCH v34 — ติดตั้งบน v33 เดิม

สำรองโค้ดเดิมและฐานข้อมูลก่อนอัปเดต ไม่ต้องลบเว็บเดิม
GitHub:
1. หน้าแรกรีโพ อัปโหลดไฟล์ Python 5 ไฟล์: app.py, angles.py, analytics_reset.py, profile_data.py, progress_analysis.py
2. เปิด static ใน GitHub อัปโหลดไฟล์ด้านใน static ของ ZIP ทั้ง 3 ไฟล์ (อย่าซ้อน static/static)
3. เปิด templates อัปโหลด index.html ทับไฟล์เดิม
4. Commit ให้ครบ รอ Render Deploy ขึ้น Live แล้ว Ctrl+Shift+R
ไม่ต้องอัปโหลดเอกสารและไฟล์ test ไม่ต้องเปลี่ยน Environment หรือ dependencies
ถ้ารัน PowerShell: หยุดเซิร์ฟเวอร์ คัดลอกเฉพาะไฟล์แพตช์ทับตำแหน่งเดิม แล้วรันวิธีเดิม

หลังติดตั้ง backend version=34; ไฟล์หน้าบ้านส่วนที่ไม่เปลี่ยนยังมีเลข32/33 ได้ตามปกติ
ข้อมูลมุมต้นแขนเทียบตัว/มุมเอนลำตัวและเวลาแต่ละรอบเริ่มจากเซตใหม่ ข้อมูลเก่าไม่ถูกสร้างค่าขึ้นเอง
กราฟแสดงครั้งละ10เซต เลือกช่วงเซตได้ เวลารายรอบแสดงล่าสุด30รอบ รายวันล่าสุด14วันที่มีข้อมูล
ปุ่มเริ่มข้อมูลวิเคราะห์ใหม่อยู่ในโปรไฟล์ของฉัน กดแล้วยืนยันก่อน ประวัติวิเคราะห์เดิมและเซตที่กำลังเล่นจะไม่กลับเข้าในกราฟใหม่ แต่จำนวนครั้งสะสม เลเวล EXP เหรียญ ปฏิทิน และข้อมูลสุขภาพยังอยู่
การรีเซตไม่มีปุ่มย้อนกลับในหน้าเว็บ (ข้อมูลฝึกต้นฉบับยังเก็บเพื่อยอดสะสม) ไม่แก้บัญชีของคนอื่น

แพตช์นี้ไม่เปลี่ยนเกณฑ์นับครั้งหรือวงจรเปิดปิดกล้อง และยังไม่ได้ติดตั้งให้บนเว็บจริง
