การรับโอนใน v14 เปิดแสดง QR/บัญชีแล้ว: กสิกร 000-0-00000-0 ยอด 50 บาท / 30 วัน
ผู้เล่นต้องสร้างบัญชีก่อนโอน เพื่อผูก VIP ให้ถูกบัญชี
ยังไม่มี SlipOK: รับสลิปเก็บในฐานข้อมูล รอผู้ดูแลตรวจยอดเงินจริงในบัญชีธนาคาร
มี SlipOK และ SMTP พร้อม: ตรวจอัตโนมัติตามเงื่อนไขเดิม ไม่ผ่านให้รอตรวจ
อัปโหลดรูปอย่างเดียวไม่ให้ VIP และห้ามอนุมัติโดยดูแค่รูปสลิป

ดูรายการสลิป/เปิดรูปส่วนตัวบนคอมเจ้าของเว็บ:
Set-Location -LiteralPath "D:\Robot Project\FitnessFormCoach_Python\FitnessFormCoach_Python"
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py receipts
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py view-slip RECEIPT_ID

หลังตรวจว่ารับเงินจริง 50 บาทเข้าบัญชีที่กำหนดแล้ว:
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py approve-vip RECEIPT_ID --transaction BANKCODE:TRANSACTION_REF --confirm-amount 50 --confirm-account 0000000000

แทน RECEIPT_ID ด้วยรหัสสลิป และ BANKCODE:TRANSACTION_REF ด้วยรหัสธนาคารผู้ส่ง 3 หลัก
กับหมายเลขธุรกรรมจากธนาคาร เช่น 004: ตามด้วยเลขอ้างอิงจริง ห้ามใช้เลขที่แต่งขึ้น
ต้องใช้เลขอ้างอิงเดียวกันกับผู้ให้บริการตรวจสลิป เพื่อกันธุรกรรมซ้ำระหว่างทั้งสองโหมด
คำสั่งนี้ใช้ได้เฉพาะบนคอมผู้ดูแล ไม่มี endpoint บนเว็บให้ผู้เล่นอนุมัติเอง
เปิดรูปแล้วมีสำเนาใน Windows Temp ให้ลบหลังตรวจเสร็จ

อีเมล: ถ้ายังไม่ตั้ง SMTP รูปจะอยู่ในฐานข้อมูลและคิวรอส่ง ไม่ได้ส่งอีเมลแล้ว
ใช้ Setup-VIP.ps1 แล้วเว้น Branch ID ว่างได้ เพื่อตั้งเฉพาะอีเมลและตรวจสลิปด้วยมือ
ใช้ Start-Configured.ps1 รันเว็บเพื่อให้ตัวส่งอีเมลทำงาน

คู่มือตรวจสลิปอัตโนมัติและกติการางวัล:
45 FITNESS COACH v14 — VIP Home 50 บาท / 30 วัน

1. อัปเดตเว็บก่อนตาม UPDATE_POWERSHELL.txt ข้อมูลบัญชีและประวัติเดิมยังอยู่
2. สมัครใช้งาน SlipOK API และรับ Branch ID กับ API key ของคุณ
   https://slipok.com/api-documentation/
   ตั้งบัญชีรับเงินของสาขา API ให้เป็นกสิกรไทย 0000000000 บัญชีเดียวเท่านั้น
   ต้องมีโควต้าตรวจสลิปเพียงพอ เงื่อนไขและค่าบริการขึ้นกับ SlipOK
3. เตรียม SMTP host, port 587/465, อีเมลผู้ส่ง และรหัสสำหรับแอป/SMTP จากผู้ให้บริการอีเมล
   อีเมลปลายทางกำหนดไว้เป็น receipts@example.com
   ไม่ต้องส่ง API key หรือรหัสผ่านมาทางแชต ไม่ใช้รหัสผู้เล่นเป็นรหัส SMTP
4. กด Ctrl+C เพื่อหยุดเว็บใน PowerShell หน้าต่างแรก แล้วรัน:

Set-Location -LiteralPath "D:\Robot Project\FitnessFormCoach_Python\FitnessFormCoach_Python"
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-VIP.ps1

   ใส่ข้อมูลตามคำถาม รหัสจะไม่แสดงขณะพิมพ์ ระบบเก็บ API key/รหัส SMTP แบบเข้ารหัส
   ด้วยบัญชี Windows ปัจจุบันใน data/vip-services.secure.json ไม่บรรจุลงไฟล์ ZIP
   ย้ายเครื่องหรือเปลี่ยนบัญชี Windows ต้องตั้งค่าใหม่
   ระบบตรวจโควต้า SlipOK และการล็อกอิน SMTP ก่อนเปิดการตรวจสลิปอัตโนมัติ
   หากตรวจไม่ผ่าน ยังเห็น QR และส่งสลิปรอตรวจด้วยมือได้ แต่จะไม่ให้ VIP อัตโนมัติ
5. ครั้งถัดไปเปิดเว็บด้วย:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Configured.ps1

   หน้าต่างที่สองเปิดแชร์มือถือด้วย Start-Share.ps1 ตามเดิม
   เปิดลิงก์ HTTPS เต็มใน Safari/Chrome และเปิดคอมกับทั้งสองหน้าต่างค้างไว้

การทำงาน VIP
- 50 บาท / 30 วัน ตามที่กำหนด ต่ออายุแล้วเพิ่มจากวันที่หมดอายุเดิมถ้ายังไม่หมด
- ต้องผ่าน SlipOK HTTP success, ตรวจ 50 THB, ธนาคาร 004, ตัวเลขบัญชีที่เปิดเผย,
  เวลาชำระไม่เกิน 24 ชั่วโมง และ reference ไม่เคยใช้
- ใช้ log=true เพื่อให้ SlipOK ตรวจบัญชีผู้รับที่คุณลงทะเบียนและสลิปซ้ำ
  การเทียบเลขที่ถูกปิดบางส่วนในเว็บเป็นการตรวจเสริม ไม่ใช่หลักฐานบัญชีเต็มด้วยตัวมันเอง
- สลิปต้อง JPG/PNG/WebP <=5 MB <=16 ล้านพิกเซล ระบบล้างข้อมูลแฝงของรูป
- ไม่ให้ VIP เพราะแนบรูปอย่างเดียว ไม่ให้เมื่อเครือข่ายล่ม/ตรวจไม่ผ่าน/สลิปซ้ำ
- กรณีธนาคารส่งผลล่าช้า แนบรูปเดิมเพื่อขอตรวจใหม่หลัง 60 วินาที ตามระยะเวลาที่ธนาคารแจ้ง
  ตรวจซ้ำได้สูงสุด 5 ครั้งต่อรูป หากยังไม่ผ่านให้ตรวจใน SlipOK dashboard ก่อน อย่าโอนซ้ำ
- ถ้า provider รับรายการแล้วแต่เครือข่าย/โปรแกรมหยุดก่อนบันทึก เว็บจะไม่อนุมัติซ้ำเอง
  ผู้ดูแลต้องตรวจรายการใน SlipOK และจัดการกรณีค้างก่อนให้ผู้ใช้ทำรายการต่อ
- สำเนารูปพร้อมสถานะตรวจถูกส่งไปอีเมลที่กำหนด มีคิวลองใหม่เมื่อส่งไม่สำเร็จ
  การส่งอีเมลล้มเหลวไม่เพิกถอน VIP ที่ตรวจธุรกรรมผ่านแล้ว ดูสถานะอีเมลในหน้า VIP
- รูปสลิปเก็บในฐานข้อมูลส่วนตัว ไม่อยู่ใน static และผู้ใช้ดูได้เฉพาะรูปของบัญชีตน
- ยังไม่มีการทดสอบชำระเงินจริงหรือส่งอีเมลจริงในสภาพแวดล้อมผู้พัฒนา

สิทธิ์และเหรียญ
- VIP เป็นสิทธิ์ของบัญชีล็อกอิน ใช้กับทุกโปรไฟล์ในบัญชีนั้น
- เหรียญเป็นของแต่ละโปรไฟล์ ไม่รวมยอดข้ามชื่อ
- ท่าที่ 3 ของแต่ละกลุ่มล็อกสำหรับ VIP: Chest-supported Row, Lying Triceps,
  Incline Press, Front Raise, Split Squat รวมถึงเริ่มเล่นจากปฏิทิน
- VIP หมดอายุระหว่างเซต ให้จบเซตที่เริ่มแล้วได้ แต่เริ่มเซต/ท่า VIP ใหม่ไม่ได้
- เซตที่บันทึกได้ 1 เหรียญทองต่อรอบที่ผ่านเกณฑ์ สองแขนต้องครบคู่
- ชาเลนจ์ Curl 20 รอบได้ 1 เหรียญม่วง และ VIP แปลง 10 ทองเป็น 1 ม่วงได้
- เวย์ตามภาพ 1 รางวัล ใช้ 50 ม่วง ส่งเป็นคำขอรอผู้ดูแลยืนยันขนาด/รสชาติ/สต็อก/ส่งมอบ
  ไม่มีการอ้างว่าส่งสินค้าแล้วโดยอัตโนมัติ ยอดถูกกันไว้และคืนได้เมื่อยกเลิกคำขอที่ยังรออยู่
- ผู้ใช้ดู/ยกเลิกคำขอในหน้า VIP Home ได้ แม้ VIP หมดอายุแล้ว
- ไฟยังเป็นสถิติวินัย ไม่มีอัตราแลกไฟในรุ่นนี้

ผู้ดูแล: คำสั่งต่อไปนี้รันบนคอมที่เก็บฐานข้อมูลเท่านั้น ไม่มีหน้าเว็บสาธารณะสำหรับแอดมิน
Set-Location -LiteralPath "D:\Robot Project\FitnessFormCoach_Python\FitnessFormCoach_Python"
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py orders
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py receipts

หลังตรวจและส่งมอบของจริงแล้ว จึงบันทึกสถานะด้วยเลขคำขอ:
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py fulfill ORDER_ID
ยกเลิกคำขอที่ยังรอและคืน 50 ม่วง:
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py cancel ORDER_ID
ตั้งค่า SMTP ถูกแล้ว สั่งลองส่งอีเมลสลิปที่ล้มเหลวใหม่:
& "..\.venv\Scripts\python.exe" -X utf8 .\manage_shop.py retry-mail RECEIPT_ID
