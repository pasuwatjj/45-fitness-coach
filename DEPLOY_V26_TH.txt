45 Fitness Coach — v26 พร้อมแทนไฟล์เดิม (24 ตุลาคม 2026 (เวลาไทย))

ไฟล์ ZIP นี้เป็นโครงการครบชุด ไม่ใช่เฉพาะไฟล์แก้ไข
ใช้หน้าเดิม กล้องเดิม โปรไฟล์ กราฟ ตารางฝึก เพื่อน แชต ชาเลนจ์ VIP QR และหลังบ้านเดิม
ไม่มีฐานข้อมูลผู้ใช้ รหัสผ่าน หรือไฟล์ตั้งค่าลับรวมมาใน ZIP
ยังไม่ได้อัปโหลด GitHub หรือ Deploy Render ให้คุณ

วิธีอัปเดต GitHub / Render
1) แตก ZIP แล้วเข้าโฟลเดอร์ 45Fitness-Ready-v26
   อัปโหลดไฟล์และโฟลเดอร์ “ข้างใน” ไปแทนที่ราก repository เดิม
   app.py, serve.py, Dockerfile, requirements.txt, static/, templates/, models/
   ต้องอยู่ระดับเดียวกัน อย่าอัปโหลดทั้งโฟลเดอร์ v26 ซ้อนอีกชั้น
   รวมไฟล์ Python ใหม่ character.py, training_modes.py, training_economy.py ด้วย
   เปลี่ยน static และ templates ให้ครบ ห้ามแทนเฉพาะ app.py
   ไม่ต้องอัปโหลด data/ หรือ *.db และไม่ต้องล้างดิสก์ Render เดิม

2) Render > Environment ตรวจค่าเดิม:
   FITNESS_PUBLIC_URL=https://four5-fitness-coach.onrender.com
   FITNESS_DATA_PATH=/data/fitness.db
   Render > Disks ต้องใช้ดิสก์เดิม Mount path /data
   ใช้ Dockerfile นี้และ python serve.py เพียงโปรเซสเดียวตามเดิม
   ฐานข้อมูลจะเพิ่มตาราง/คอลัมน์ใหม่อัตโนมัติ โดยคงบัญชีและข้อมูลเดิม
   หากสำรองฐานข้อมูล ให้สำรอง SQLite อย่างสอดคล้องกันก่อนอัปเดต ไม่คัดลอกไฟล์ขณะกำลังเขียนโดยไม่จัดการ WAL

3) Commit ไฟล์ แล้ว Render > Manual Deploy > Deploy latest commit
   รอ Live แล้วเปิด:
   https://four5-fitness-coach.onrender.com/45-fitness-coach
   กด Ctrl+Shift+R หรือรีเฟรชแบบไม่ใช้แคชหนึ่งครั้ง
   ไฟล์ JS/CSS หน้าเว็บใช้ URL ?v=26

4) การให้สิทธิ์แอดมินยังใช้ระบบเดิม บัญชีต้องสมัครอยู่ก่อนแล้ว
   Render Shell:
   FITNESS_DATA_PATH=/data/fitness.db python manage_admin.py --email pasuwatoyasumi7@gmail.com
   รีเฟรชหลังเข้าสู่ระบบด้วยบัญชีนั้น ไม่ต้องสมัครซ้ำ
   คำสั่งนี้ไม่สร้างแอดมินให้อัตโนมัติตามชื่ออีเมล
   VIP ยังใช้ QR และบัญชีเดิม หากไม่ได้ตั้งบริการตรวจสลิป แอดมินตรวจเงินจริงก่อนอนุมัติตามเดิม

สิ่งใหม่และวิธีใช้
• ตัวเลือกสลับแขนอัตโนมัติอยู่ใกล้ปุ่มขยายภาพกล้อง
  ใช้กับท่าแขนที่รองรับซ้ายและขวา เห็นไหล่–ศอก–ข้อมืออีกด้านชัดต่อเนื่องประมาณ 0.45 วินาทีจึงสลับ
  ไม่บังคับเห็นสะโพกเพื่อ “เลือกด้าน” แต่การประเมินฟอร์มบางท่ายังต้องเห็นลำตัว/สะโพกด้วย
  ท่าตั้งต้นของแต่ละข้างเก็บแยกไว้ การเคลื่อนไหวที่ค้างขณะสลับจะไม่ถูกนับต่อข้ามข้าง
  เปิด/ปิดสวิตช์ระหว่างเล่นจะบันทึกเซตเดิมและเริ่มเซตใหม่ ไม่รวมสองรูปแบบไว้ในเซตเดียว

• ระดับเริ่มต้นคือผู้เริ่มต้น สีเหลือง ปรับความคลาดเคลื่อน/มุม Curl ได้ตามเดิม
  Pro สีม่วง และ Expert สีแดงใช้เกณฑ์เฉพาะท่าที่เข้มขึ้นตามลำดับ
  เลือกระดับก่อนเริ่มเซต เปลี่ยนระดับระหว่างเซตไม่ได้
  เกณฑ์เหล่านี้เป็นกติกาเกมทดลอง ไม่ใช่มุมมาตรฐานสากลสำหรับทุกคนหรือการรับรองฟอร์มทางการแพทย์
  รอบผิดเกณฑ์แสดงเหรียญแดงแตกและเสียงคล้ายกระจกแตก แยกจากเสียงเหรียญที่นับสำเร็จ
  เปิดเสียงก่อน เสียงแตกจะเคารพปุ่มปิดเสียงและตัวเลือกเสียงเหรียญ

• เหรียญฝึกใหม่แยกจากทองเดิมและม่วงชาเลนจ์เดิมโดยสิ้นเชิง
  เหรียญได้จากจำนวนครั้งที่ผ่านและบันทึกเซตสำเร็จ: ผู้เริ่มต้นเหลือง / Pro ม่วง / Expert แดง
  ทุกบัญชีที่เข้าสู่ระบบแลกเหรียญได้ ไม่ต้อง VIP:
  1,000 เหลือง → 1 สากล หรือ 100 ม่วง → 1 สากล หรือ 10 แดง → 1 สากล
  ใช้ชนิดใดชนิดหนึ่งต่อรายการ ยอดแยกตามชื่อผู้เล่นในบัญชี
  VIP Home เท่านั้นที่ส่งคำขอแลกเวย์ ใช้ 100 เหรียญสากลต่อคำขอ
  เป็นคำขอให้ผู้ดูแลยืนยันสินค้า/จัดส่ง ไม่ใช่การจัดส่งอัตโนมัติ
  ยกเลิกคำขอใหม่ที่ยังรอจะคืน 100 สากล ส่วนคำขอเก่าจะคืน 50 ม่วงเดิม
  รายการที่ดำเนินการแล้วไม่คืนซ้ำ ทอง/ม่วงเดิมยังแสดงแยกไว้ แต่การแลกทองแบบเก่าปิดแล้ว

• ปุ่มตัวละครของฉันมีตัวละครผู้ใหญ่สไตล์บล็อก 3 มิติที่สร้างใหม่ในโค้ด
  ลากหมุนได้ 360 องศา ใช้ปุ่มหมุน/ปุ่มลูกศรได้ เลือกชายหรือหญิง
  มีผม 6 แบบ ปรับสีผม สีผิว และสีกางเกง/ชุดกีฬาได้ฟรี
  ชายใส่กางเกงขาสั้น หญิงใส่สปอร์ตบราและกางเกงขาสั้น
  รูปลักษณ์บันทึกกับบัญชี ใช้ร่วมกันทุกชื่อผู้เล่นของบัญชีนั้น
  การเติบโตคิดจากเซตจริงของแต่ละโปรไฟล์แยกแขน อก หลัง ไหล่ ขา
  แขนซ้าย/ขวาเติบโตแยกตามจำนวนครั้ง สูงสุดของภาพแต่ละส่วนที่ 5,000 ครั้ง
  ตัวละครเริ่มผอมเมื่อไม่มีประวัติ หากมีเซตเก่าอยู่แล้วจะสะท้อนประวัตินั้น
  ส่วนสูง/น้ำหนักใช้ข้อมูลร่วมกับโปรไฟล์ มีผลต่อสัดส่วนภาพในขอบเขตจำกัด
  ข้อมูลนี้ไม่ใช้คำนวณมวลกล้ามเนื้อจริง ผู้อื่นเห็นรูปลักษณ์เดียวกัน แต่ไม่เห็นตัวเลขส่วนสูง/น้ำหนัก

เช็กหลังอัปเดต
- เข้าบัญชีเดิม เห็นโปรไฟล์เดิม เลือกภาษาไทย/อังกฤษ เปิดตัวละครและลองบันทึก
- เปิดกล้องผ่าน HTTPS อนุญาตสิทธิ์กล้อง ทดลองผู้เริ่มต้นก่อน แล้วพักเซตเพื่อบันทึกเหรียญ
- ทดลองสลับแขนเมื่อเห็นอีกด้านชัด ตรวจว่าเซตค้างไม่เพิ่มครั้งเอง
- เปิดหน้าแลกรางวัล บัญชีธรรมดาเห็นอัตราแลก ส่วนคำขอเวย์ต้อง VIP
- ทดสอบหน้าเดิม ตาราง กราฟ เพื่อน ชาเลนจ์ VIP และหลังบ้านตามสิทธิ์
