45 Fitness — PATCH v32 (ต่อจาก v31 เท่านั้น)
แตก ZIP ก่อน อัปโหลดไฟล์ด้านในตามตำแหน่งเดิม ไม่อัปโหลด ZIP เป็นโค้ด และไม่สร้างโฟลเดอร์ 45Fitness-PATCH-v32 ซ้อนใน repository

ไฟล์ใช้งานจริง 7 ไฟล์:
ROOT — หน้าแรกของ GitHub repository ระดับเดียวกับ requirements.txt:
  administration.py (ไฟล์ใหม่)
  accounts.py
  app.py
  community.py
โฟลเดอร์ templates:
  index.html
โฟลเดอร์ static:
  admin-management.js (ไฟล์ใหม่)
  community.js

ขั้นตอนผ่านหน้าเว็บ GitHub:
1. สำรอง repository และฐานข้อมูลก่อน ใช้ repository ที่อัปโหลด v31 ครบแล้ว
2. สร้าง branch สำหรับแพตช์นี้ ถ้าโฮสต์ auto-deploy ให้รวมเข้า branch ที่โฮสต์ใช้งานเมื่ออัปโหลดครบแล้วเท่านั้น
3. หน้าแรก repository > Add file > Upload files > เลือก administration.py, accounts.py, app.py, community.py จาก ZIP > Commit changes
4. เปิดโฟลเดอร์ templates > Add file > Upload files > เลือก index.html จาก templates ใน ZIP > Commit changes
5. เปิดโฟลเดอร์ static > Add file > Upload files > เลือก admin-management.js และ community.js จาก static ใน ZIP > Commit changes
6. ตรวจ path จริง: administration.py ที่ root, templates/index.html, static/admin-management.js, static/community.js ห้ามวาง index.html หรือ JavaScript ไว้ผิดโฟลเดอร์
7. รวม branch เมื่อครบ 7 ไฟล์ แล้ว deploy/restart แอปตามโฮสต์เดิม
8. เปิดเว็บ Ctrl+Shift+R เข้าบัญชีแอดมิน > หลังบ้าน > ค้นหาสมาชิก > จัดการเหรียญ / ระงับบัญชี
9. เลือกโปรไฟล์ของบัญชีนั้น ชนิดเหรียญ เพิ่ม/ลด จำนวนเต็ม 1–1,000,000 และเหตุผล แล้วบันทึก ตรวจยอดก่อน→หลังในประวัติ
10. ทดสอบกับบัญชีทดสอบก่อน หากต้องทำรายการเท่ากันอีกครั้งโดยตั้งใจ ให้เปลี่ยนเหตุผล/รายละเอียดหรือเปิดหน้าใหม่ การกดซ้ำรายการเดิมในฟอร์มจะคืนผลเดิมเพื่อป้องกันเหรียญซ้ำ

ไม่มีการเติม/หักเหรียญจริงหรือระงับบัญชีบนเว็บจริงในระหว่างจัดทำแพตช์นี้
เพิ่ม/ลดได้เฉพาะเหรียญฝึกมือใหม่สีเหลือง โปรสีม่วง ผู้เชี่ยวชาญสีแดง และสากล ไม่ใช่เหรียญทองเก่าหรือเหรียญชาเลนจ์เก่า
การปรับเหรียญไม่เพิ่ม EXP/LV ไม่เพิ่มเซตหรือครั้ง และไม่เพิ่มอันดับการฝึก
ระบุเหตุผลทุกครั้ง ยอดห้ามติดลบ บันทึกแอดมิน ผู้รับ โปรไฟล์ เวลา ชนิด จำนวน และก่อน/หลังในธุรกรรมเดียวกัน
ระงับบัญชีจะปิดการเข้าใช้บัญชีและคำขอจากเซสชันเดิม ผู้ถูกระงับยังออกจากระบบได้ ไม่มีการลบข้อมูล ยกเลิกระงับแล้วเข้าใช้ได้ ไม่อนุญาตระงับตัวเองหรือแอดมินคนสุดท้าย
ประวัติแลกเหรียญทั้งระบบอ่านรายการแลกจริงที่มีหลักฐานหักเหรียญต้นทางและเพิ่มเหรียญสากลใน ledger รวมรายการเดิมที่มีอยู่ ไม่สร้างประวัติย้อนหลังปลอม แสดงหน้าละ 50 รายการ

ไม่ต้องติดตั้ง dependency ใหม่ ไม่ต้องล้างฐานข้อมูล ตารางใหม่สร้างอัตโนมัติในฐานข้อมูลเดิม
ห้ามแทนที่หรือลบ data/, settings.json, environment variables, รูปภาพ, โมเดล หรือไฟล์อื่นที่ไม่อยู่ในแพตช์
