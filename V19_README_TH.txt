45 FITNESS COACH v19

1. หน้าหลักใช้ภาพผู้ใช้เสื้อเหลืองถือดัมเบลเป็นพื้นหลังเต็มกรอบ
   ใช้รูปต้นฉบับที่ส่งมา ไม่สร้างหน้าหรือรูปร่างใหม่ มีไล่สีเข้มช่วยอ่านตัวหนังสือ
2. เก็บมุมต่อเซตแบบแยกด้านและแยก 2D/estimated_3D:
   ค่าเฉลี่ย ต่ำสุด สูงสุด SD จำนวนเฟรม จุดกลับตัวเฉลี่ยและ SD
   เลือกวันที่ในโปรไฟล์เพื่อดูกราฟช่วงมุม และเปรียบเทียบเซตก่อนหน้าท่า/ด้าน/วิธีวัดเดียวกัน
   ข้อมูลเริ่มเก็บหลังอัปเดต ไม่มีการสร้างข้อมูลย้อนหลังก่อน v19
   ค่าเฉลี่ยรวมช่วงยกและลดจึงไม่เท่ากับมุมเป้าหมาย SD ไม่ใช่คะแนนความผิด
   คำแนะนำความสม่ำเสมอใช้เกณฑ์เกมโดยประมาณ ไม่ใช้บอกเปอร์เซ็นต์ฟอร์มถูกหรือวินิจฉัย
   จุดกลับตัวรวมรอบที่ตรวจพบ แม้บางรอบไม่ได้คะแนน; เซตไม่ครบหรือไม่เกิดรอบอาจมีแต่สถิติเฟรม
3. แชตเฉพาะเพื่อนที่ตอบรับแล้ว ส่งข้อความได้ 1–2000 ตัวอักษร
   เก็บข้อความในฐานข้อมูล เรียกดูย้อนหลังได้ ป้องกันส่งซ้ำจากการกด/ลองใหม่
   ไม่รองรับรูป/ไฟล์ในแชตรุ่นนี้ ไม่มีการแจ้งเตือนเมื่อปิดเว็บ
   ป้าย 🟢 ออนไลน์ใช้ heartbeat เมื่อเปิดหน้าเว็บอยู่ อาจหน่วงประมาณ 75 วินาที
   สถานะในหน้ารายชื่อ/โปรไฟล์อัปเดตเมื่อเปิดดู ส่วนแชตอัปเดตประมาณทุก 3 วินาที
4. หลังบ้านแอดมินเพิ่มโหมดปรับปรุง
   ต้องหยุดและบันทึกกล้องที่กำลังเล่นก่อน จึงกดปิดรับผู้เล่นได้
   ปิดการเริ่มเล่นและแชตของสมาชิกทั่วไป หน้าแรกและเข้าสู่ระบบยังใช้ได้
   แอดมินยังเข้าไปเปิดกลับได้ สถานะเก็บในฐานข้อมูลข้ามการรีสตาร์ต
   ไม่ใช่ปุ่มตัดไฟ/ปิดเครื่อง เพราะถ้าเซิร์ฟเวอร์ดับจริงจะเปิดผ่านเว็บไม่ได้
5. ระบบกล้องและเกณฑ์นับเดิมคงไว้ เพิ่มเพียงตัวเก็บสถิติหลังอ่านมุมได้
   static/session-camera.js ไม่เปลี่ยนแม้แต่ไบต์เดียวจาก v18
6. แชร์และรันยาว:
   เก็บรหัสลิงก์แชร์ในฐานข้อมูล ไม่เปลี่ยนทุกครั้งที่เซิร์ฟเวอร์รีสตาร์ต
   Start-Share.ps1 ตรวจเซิร์ฟเวอร์ทุก 10 วินาที และลงทะเบียนลิงก์เดิมคืนหากเซิร์ฟเวอร์กลับมา
   หลังอัปเดต v19 ครั้งแรกต้องรับลิงก์แชร์ใหม่; หลังจากนั้นคีย์คงเดิมในฐานข้อมูลเดียวกัน
   Start-AlwaysOn.ps1 ใช้ตัวเฝ้ารันเดิม แต่รัน Waitress และป้องกัน Windows หลับขณะที่ตัวเฝ้ารันยังอยู่
   การ Shutdown/รีบูต/เน็ตหลุด/ปิด tunnel ยังทำให้เว็บเข้าไม่ได้ ไม่รับประกัน uptime
   Enable-AutoStart.ps1 ตั้งให้เริ่มเมื่อผู้ใช้ Windows คนนี้ล็อกอิน; Disable-AutoStart.ps1 ยกเลิก
   งานเริ่มอัตโนมัติไม่ได้เปิด Quick Tunnel ให้ ต้องเปิด Start-Share.ps1 เอง

ลำดับอัปเดตครั้งต่อไป
แอดมิน > หลังบ้าน > โหมดปรับปรุง > หยุดเซิร์ฟเวอร์จาก PowerShell
ติดตั้งไฟล์อัปเดต > รันเซิร์ฟเวอร์ > เข้าบัญชีแอดมิน > เปิดเว็บกลับ
ครั้งแรกที่ลง v19 ยังไม่มีปุ่มโหมดนี้ในรุ่นเก่า ให้หยุดเว็บเดิมก่อนตามปกติ
ไม่ลบ data และอย่าแตกไฟล์ทับตอนเซิร์ฟเวอร์ยังรันอยู่

รันเบื้องหลังบนคอม (หลังหยุดหน้าต่างเว็บปกติแล้ว)
Set-Location -LiteralPath "D:\Robot Project\FitnessFormCoach_Python\FitnessFormCoach_Python"
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-AlwaysOn.ps1
จากนั้นเปิด Start-Share.ps1 อีกหน้าต่างสำหรับลิงก์มือถือ
หยุดเซิร์ฟเวอร์เบื้องหลังด้วย Stop-AlwaysOn.ps1

โฮสต์และ Google
ยังไม่ได้เผยแพร่เว็บจริงหรือซื้อโฮสต์/โดเมนให้ เพราะยังไม่มีโดเมนและเครื่องปลายทาง
เพิ่ม compose.yaml + Caddyfile สำหรับรัน Flask/MediaPipe เดิมบนโฮสต์ CPU พร้อม HTTPS
ต้องมีเครื่องรองรับ Docker, พื้นที่ข้อมูลถาวร, DNS ชี้เข้าเครื่อง และเปิดพอร์ต 80/443
สร้างไฟล์ .env ในเครื่องปลายทาง: FITNESS_DOMAIN=ชื่อโดเมนจริง
จากนั้น docker compose up -d --build
อย่าใช้ docker compose down -v เพราะลบข้อมูลถาวร
หากย้ายจากคอม ต้องสำรองและย้ายฐานข้อมูลเดิมก่อน จึงจะมีสมาชิก ยศ เหรียญ และแชตเดิม
ระบบกล้องมี state ใน process ใช้หนึ่ง instance ตาม compose เท่านั้น
ยืนยันโดเมนใน Search Console แล้วส่ง /sitemap.xml; ไม่รับประกันว่าจะค้นเจอทันที
Quick Tunnel เป็นลิงก์ทดลอง ไม่ใช่โฮสต์ถาวร

- ถ้า local เข้าไม่ได้: ดู data/background-errors.log และสถานะเครื่อง/ไฟ/Windows Sleep
